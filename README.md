# claude-backend-skills
Collection of general Claude Code skills for backend project analysis, architecture design, code generation, code review and Mermaid diagram generation.
自用后端开发专属 Claude Code 技能合集，一键安装即可使用。

## 安装方式
```bash
npx skills add Tyreezhang/claude-backend-skills
```
### 内置技能 & 使用指令
1. 全盘分析整个项目架构
- 帮我深度分析整个项目的技术栈、架构分层、业务模块、代码结构、业务需求和优化建议
2. 生成架构图 / 模块关系图
- 给我生成这个项目的整体架构分层图和模块依赖Mermaid图
3. 按项目风格生成新功能 CRUD
- 按照我当前项目的代码规范和分层结构，给我生成一套完整的XX模块CRUD代码
4. 代码全局评审与优化
- 对整个项目做一次代码评审，帮我找出潜在bug、不规范代码、冗余逻辑和性能优化点
包含技能列表
project-universal-analyzer：项目全盘架构分析
project-mermaid-diagram：自动生成架构 / 模块 Mermaid 图表
project-feature-generator：跟随项目风格生成新业务模块代码
project-code-review-optimize：全局代码评审、Bug 排查与性能优化
