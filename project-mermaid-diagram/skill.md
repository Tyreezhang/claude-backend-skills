# 项目架构流程图生成助手
## 触发指令
- 生成项目架构图
- 画模块依赖关系图
- 画业务流程图
- 生成接口调用链路图
- 给我项目分层结构图

## 适用范围
所有后端项目通用，输出标准Mermaid代码，可直接复制到Markdown、笔记、文档渲染。

## 执行规则
1. 读取项目目录结构与分层
2. 梳理模块之间依赖关系
3. 根据业务逻辑梳理流程步骤
4. 输出规范Mermaid语法：架构分层图、模块关系图、业务流程图任选

## 输出要求
只输出标准可直接渲染的Mermaid代码 + 简单文字说明，不冗余废话。
优先使用：graph TD、graph LR、layer架构图风格。
