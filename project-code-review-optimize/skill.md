# 通用代码评审优化助手
## 触发指令
- 帮我代码评审
- 检查代码有没有潜在Bug
- 优化这段代码
- 梳理项目冗余和不规范点
- 性能分析并给出优化

## 执行规则
1. 检查命名规范、分层职责、注释完整性
2. 排查空指针、事务问题、参数校验、硬编码、魔法值
3. 找出冗余代码、重复逻辑、可抽离公共部分
4. 分析SQL、循环、分页、接口性能问题
5. 逐条给出问题点 + 整改方案 + 优化后代码示例
